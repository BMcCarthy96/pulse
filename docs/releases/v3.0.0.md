# Pulse v3.0.0 — investigation workspace release

Status: implementation complete in the repository. The public Vercel demo URL is linked from the README;
account-owned Railway settings, an immutable CI evidence link, and the GitHub tag are the remaining
release handoff steps.

## Highlights

- One-click demo sessions create isolated synthetic OPS tenants with a one-hour TTL, a
  deterministic outage fixture, reset support, five-minute cleanup, and capacity protection.
- Incident investigations are durable workspaces with redacted, deep-linked evidence; cited
  hypotheses; streamed activity; live/deterministic disclosure; and model, prompt, token, cost, latency,
  and trace telemetry.
- AI actions are restricted to four allow-listed operations and require OPS approval. Target state
  is revalidated, proposals are atomically claimed, stale proposals return 409, and audit entries
  record approval and outcome.
- Live AI is budgeted deployment-wide at 30 investigations/day, two per
  session, ten per user/hour, 30 per organization/day, $0.20 per run, and $5/day. Deterministic
  recorded evidence synthesis remains available when credentials are unavailable.
- Security and supply-chain proof includes CodeQL, Dependabot, dependency review, secret scanning,
  GHCR image publishing, SBOM, provenance attestations, accessibility checks, Lighthouse budgets,
  k6 thresholds, OpenAPI contracts, and deterministic safety evals.

## Verification

The release gate includes lint, typecheck, unit coverage, integration tests against Postgres and
Redis, summary and investigation evals, production web build, focused accessibility checks, the
full browser demo flow, and the authoritative GitHub Actions worker-image build.
